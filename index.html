📚 Prontuario Técnico (7 Pasos)

1. Vector Desplazamiento

$$\Delta \vec{r} = (x_2 - x_1, y_2 - y_1)$$

💡 Tip: Respeta siempre la regla de signos.

2. Magnitud

$$|\Delta \vec{r}| = \sqrt{(\Delta x)^2 + (\Delta y)^2}$$

3. Dirección ($\theta$)

$$\theta = \arctan\left(\frac{\Delta y}{\Delta x}\right) + \text{Ajuste}$$

4. Pendiente ($m$)

$$m = \frac{y_2 - y_1}{x_2 - x_1}$$

5. Punto-Pendiente

$$y - y_1 = m(x - x_1)$$

6. Forma Explícita

$$y = mx + b$$

7. Forma General

$$Ax + By + C = 0$$
